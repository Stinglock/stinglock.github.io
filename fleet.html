Future fleet paths — if you wanted to specialise

The hangar already supports several directions beyond the two-man mission grind. None of this is committed — it's what's already sitting in the hangar or one skill away, grouped by playstyle.

Path A

Mission runner

The default track — already underway

Stabber → Hurricane → Maelstrom/Typhoon. L1–L4 security missions, standings-gated. Highest ISK/hour ceiling for the least new-skill investment since every hull is already owned.

Path B

Small-gang PvP

Slasher, Condor, Rifters, Jaguar

Tackle frigates are already flyable today. The Jaguar (assault frigate) and eventually the Rapier (force recon, needs Minmatar Cruiser V) turn this into a real roaming kit. Doesn't touch the mission-runner skill queue much — mostly separate support skills (Cap Systems Op, Mechanics).

Path C

Exploration

Magnate, Heron, Imicus, 2× Probe

Five exploration-capable frigates already owned and flyable, across all four empire races. Relic/data site running for LP and salvage, or wormhole scouting later. Astrometrics and hacking/archaeology skills are already in the rebuilt plan (§10).

Path D

Logistics & support

Mammoth, Burst

Mammoth handles hauling between Rens and the stranded hulls at Hek/Josekorn until the courier contracts clear. Burst is a shield-logi frigate — pairs naturally with Coreun's armor-tanked Myrmidon/Dominix for a proper two-man rep chain later.

Path E

T3 / covert endgame

Loki, Rapier, Hound

All three sit behind level-V skills (Minmatar Cruiser V, Electronics Upgrades V). Loki is the modular do-anything hull; Rapier and Hound are fleet-support/solo-stealth tools rather than mission runners. ~20 days out at the earliest.

Path F

Fund Coreun's drone track

Myrmidon → Dominix → Ishtar

Not Stinglock's hull, but funded from Stinglock's wallet. See Pilots and Content for the full progression and what it unlocks.
